# csharp-lsp

适用于 Claude Code 的 C# 语言服务器，提供代码智能与诊断功能。

## 支持的扩展名
`.cs`

## 安装

### 通过 .NET 工具安装（推荐）
```bash
dotnet tool install --global csharp-ls
```

### 通过 Homebrew 安装（macOS）
```bash
brew install csharp-ls
```

## 环境要求
- .NET SDK 6.0 或更高版本
