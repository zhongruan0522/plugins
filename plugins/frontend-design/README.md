# Frontend Design 插件

生成独具特色、可用于生产环境的前端界面，避免千篇一律的 AI 审美风格。

## 功能

在前端相关工作上，Claude 会自动使用此技能。生成的生产级代码具备：

- 大胆的美学选择
- 独特的字体与配色方案
- 高冲击力的动画与视觉细节
- 贴合上下文的实现

## 用法

```
"为一个音乐流媒体应用创建仪表盘"
"为一家 AI 安全初创公司构建落地页"
"设计一个支持深色模式的设置面板"
```

Claude 会选定一个清晰的美学方向，并以细致入微的细节把控实现生产级代码。
